# 100-days-python
Ever try to complete 100 python projects in 100 days? Yeah, me neither. In this repo I take on the 100 Days of Code Challenge for Python by App Brewery; however, theres a twist. I will be completing it in less than 100 days. Since I have prior experence in Python (and made it to day 31 years ago), I will be speed running the first portion of the 100 days. Below, is a list indexing the programs I have made each day. Feel free to peruse.

**The Why**

What's the point of learning a new programming language when it's just as easy to ask AI to write you a program? I've been asking myself this a lot lately. Especially, as I go through this challenge. It's come down to one thing as I stubbornly move forward with sharpening my python skils. The process. I'm not just looking for an end result. I truly enjoy the process in which programs are created and skill are learned while programming. Now, dont get me wrong. I will still go to my web browser and ask a very targeted question on python niceties when I'm stumped, but the overall goal to to make these programs myself.
